How discovery works

Passive by design

Orange Test queries crt.sh from the backend, normalizes certificate names, then resolves A and AAAA records with a capped DNS worker pool. It never probes ports, sends HTTP checks, or attempts authentication.

Certificate Transparency→DNS A / AAAA→Cloudflare CIDR match
Coverage note

CT is not a DNS inventory

Certificate Transparency records can miss valid subdomains that have no matching certificate history. The first version intentionally avoids brute-force wordlists.
